# Buat AI (text) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An "Asisten AI" panel in the `/buat` editor that writes captions from a brief, suggests post ideas, rewrites the caption and adds hashtags through 9Router, without ever saving or publishing on its own.

**Architecture:** `src/lib/nine-router.ts` is the raw HTTP client (like `instagram.ts`). `src/lib/ai.ts` validates requests, builds prompts, parses answers, enforces a 100-per-24-hours limit and logs to a new `ai_generations` table. `src/app/(app)/buat/ai-actions.ts` exposes one server action; `ai-assistant.tsx` is the client panel mounted in `post-editor.tsx`. Choices shared by client and server live in `src/lib/ai-options.ts`.

**Tech Stack:** Next.js 16.4 server actions, React 19, Supabase (service role), vitest, 9Router OpenAI-compatible `/v1/chat/completions`.

**Spec:** `docs/superpowers/specs/2026-10-16-buat-ai-design.md`

## Global Constraints

- UI copy is Bahasa Indonesia; code comments are English.
- 9Router is called only from server code; the key goes only in the `Authorization` header and never into errors or logs.
- Every request body sends `stream: false` (9Router answers SSE otherwise).
- AI output never saves, schedules or publishes anything; it only fills the editor.
- Server actions call `assertLocalRequest()` first and validate their input as `unknown`.
- Lengths are counted in code points (`Array.from`), like `inspectCaption` and Postgres.
- New tables: RLS on, no policies, privileges revoked from `anon` and `authenticated`.
- No new npm dependencies.
- `ROUTER_MODEL=cc/claude-haiku-4-5-20251001`.

## Review Focus

1. Enter in the panel's Audiens input must not submit the surrounding post form (its first button is **Jadwalkan**). Checked by hand in Task 6, since the repo has no DOM test setup.
2. A 200 whose content is a provider notice ("Gemini 3.5 Flash is no longer available…") must surface as an error showing that text, not as a caption. Covered in Task 3.
3. An emoji-heavy caption of exactly 2,200 code points is accepted and 2,201 is refused. Covered in Task 2.
4. A caption that already has 27 hashtags gets at most 3 new ones, and none that differ from an existing tag only by case. Covered in Task 3.
5. An idea longer than 300 characters must still be usable through **Jadikan topik**. Ideas are cut to the topic limit, covered in Task 3.

```ts
import 'server-only'
import { env } from './env'

/** Combos may try several providers in turn before one answers. */
const REQUEST_TIMEOUT_MS = 60_000
/** Room for three captions in JSON; the models stop well before this. */
const MAX_TOKENS = 4096

export interface ChatMessage {
  role: 'system' | 'user'
  content: string
}

export class RouterApiError extends Error {
  override name = 'RouterApiError'

  constructor(
    message: string,
    /** HTTP status, or 0 when 9Router could not be reached or did not answer in time. */
    readonly status: number,
  ) {
    super(message)
  }
}

type Json = Record<string, unknown>

const isObject = (value: unknown): value is Json => typeof value === 'object' && value !== null

/** 9Router wraps provider errors as `{ error: { message: "[provider/model] [status]: …" } }`. */
function errorMessage(body: unknown, status: number): string {
  const message = isObject(body) && isObject(body.error) ? body.error.message : undefined
  return typeof message === 'string' && message !== '' ? message : `HTTP ${status}`
}

function readContent(body: unknown): string {
  const choice = isObject(body) && Array.isArray(body.choices) ? body.choices[0] : undefined
  const content = isObject(choice) && isObject(choice.message) ? choice.message.content : undefined
  if (typeof content !== 'string' || content.trim() === '') {
    throw new RouterApiError('Respons 9Router tanpa isi', 200)
  }
  return content
}

/**
 * One chat completion, returning the answer's text. `stream: false` must be explicit: without it
 * 9Router answers with SSE. The key travels only in the header; errors never carry the URL or headers.
 */
export async function chatCompletion(messages: ChatMessage[]): Promise<string> {
  const url = `${env('ROUTER_API_BASE_URL').replace(/\/+$/, '')}/chat/completions`
  const init: RequestInit = {
    method: 'POST',
    headers: { authorization: `Bearer ${env('ROUTER_API_KEY')}`, 'content-type': 'application/json' },
    body: JSON.stringify({ model: env('ROUTER_MODEL'), messages, stream: false, max_tokens: MAX_TOKENS }),
    signal: AbortSignal.timeout(REQUEST_TIMEOUT_MS),
  }
  const response = await fetch(url, init).catch((error: unknown) => {
    const reason = isObject(error) && typeof error.name === 'string' ? error.name : 'unknown'
    throw new RouterApiError(`9Router tidak bisa dihubungi (${reason})`, 0)
  })
  const body: unknown = await response.json().catch(() => null)
  if (!response.ok) throw new RouterApiError(errorMessage(body, response.status), response.status)
  return readContent(body)
}
```

- [ ] **Step 5: Write validation and prompts** (`src/lib/ai.ts`)

```ts
import 'server-only'
import {
  AUDIENCE_MAX_LENGTH,
  GOALS,
  REWRITE_STYLES,
  TONES,
  TOPIC_MAX_LENGTH,
  type AiRequest,
  type Brief,
  type RewriteStyle,
} from './ai-options'
import { CAPTION_MAX_HASHTAGS, CAPTION_MAX_LENGTH, findHashtags } from './caption'
import type { ChatMessage } from './nine-router'

const MAX_PHOTOS = 10

type Json = Record<string, unknown>

const isObject = (value: unknown): value is Json => typeof value === 'object' && value !== null
/** Own keys only: `'toString' in GOALS` is true. */
const isChoice = <T extends object>(choices: T, value: unknown): value is keyof T =>
  typeof value === 'string' && Object.hasOwn(choices, value)
/** Code points, as Instagram, the editor counter and Postgres count them. */
const lengthOf = (text: string) => Array.from(text).length

export type ParsedRequest = { request: AiRequest } | { error: string }

function parseBrief(input: unknown): Brief | string {
  if (!isObject(input)) return 'Permintaan tidak valid.'
  const topic = typeof input.topic === 'string' ? input.topic.trim() : ''
  const audience = typeof input.audience === 'string' ? input.audience.trim() : ''
  const { goal, tone, photoCount } = input

  if (!topic) return 'Isi topik dulu.'
  if (lengthOf(topic) > TOPIC_MAX_LENGTH) return `Topik maksimal ${TOPIC_MAX_LENGTH} karakter.`
  if (lengthOf(audience) > AUDIENCE_MAX_LENGTH) return `Audiens maksimal ${AUDIENCE_MAX_LENGTH} karakter.`
  if (!isChoice(GOALS, goal) || !isChoice(TONES, tone)) return 'Tujuan atau nada tidak dikenal.'
  if (typeof photoCount !== 'number' || !Number.isInteger(photoCount) || photoCount < 0 || photoCount > MAX_PHOTOS) {
    return 'Jumlah foto tidak valid.'
  }
  return { topic, goal, tone, audience, photoCount }
}

/** Validates what the editor sent. The server action's parameter type is only a hint. */
export function parseAiRequest(input: unknown): ParsedRequest {
  if (!isObject(input)) return { error: 'Permintaan tidak valid.' }
  const { task } = input
  if (task === 'captions' || task === 'ideas') {
    const brief = parseBrief(input.brief)
    return typeof brief === 'string' ? { error: brief } : { request: { task, brief } }
  }
  if (task !== 'rewrite' && task !== 'hashtags') return { error: 'Permintaan tidak valid.' }

  // Textareas submit CRLF; count newlines once, as the editor and Instagram do.
  const caption = typeof input.caption === 'string' ? input.caption.replace(/\r\n/g, '\n') : ''
  if (!caption.trim()) return { error: 'Tulis caption dulu.' }
  if (lengthOf(caption) > CAPTION_MAX_LENGTH) return { error: 'Caption lebih dari 2.200 karakter.' }
  if (task === 'hashtags') {
    return findHashtags(caption).length >= CAPTION_MAX_HASHTAGS
      ? { error: 'Caption sudah memakai 30 hashtag.' }
      : { request: { task, caption } }
  }
  return isChoice(REWRITE_STYLES, input.style)
    ? { request: { task, style: input.style, caption } }
    : { error: 'Gaya ubah caption tidak dikenal.' }
}

const SYSTEM_PROMPT = [
  'Kamu penulis caption Instagram untuk satu akun bisnis atau kreator di Indonesia.',
  'Aturan:',
  '- Tulis dalam Bahasa Indonesia yang natural, kecuali brief jelas memakai bahasa lain.',
  '- Patuhi batas Instagram: caption maksimal 2.200 karakter, 30 hashtag, dan 20 mention.',
  '- Jangan pakai Markdown seperti **tebal**, _miring_, atau judul. Instagram tidak merendernya.',
  '- Jangan mengarang fakta atau klaim yang tidak ada di brief, misalnya harga, tanggal, lokasi, stok terbatas, atau "kualitas premium".',
  '- Balas HANYA dengan satu objek JSON sesuai format yang diminta, tanpa teks lain.',
].join('\n')

const CAPTION_SHAPE =
  'Setiap caption terdiri dari 2–4 paragraf pendek, sekitar 300–700 karakter sebelum hashtag: kalimat pembuka yang menarik, isi, lalu ajakan bertindak (CTA) yang sesuai tujuan. Tutup dengan 3–8 hashtag relevan di baris terakhir.'

const REWRITE_INSTRUCTIONS: Record<RewriteStyle, string> = {
  santai: 'Tulis ulang caption dengan nada lebih santai dan akrab.',
  profesional: 'Tulis ulang caption dengan nada lebih profesional dan rapi.',
  singkat: 'Tulis ulang caption supaya lebih singkat, kira-kira setengah panjangnya.',
  panjang: 'Tulis ulang caption supaya lebih panjang dan lebih rinci, tanpa menambah fakta baru.',
  cta: 'Tambahkan satu ajakan bertindak (CTA) yang jelas di akhir isi caption, sebelum hashtag. Jangan ubah bagian lain.',
}

/** Owner text goes between triple quotes, apart from the instructions. */
const quote = (text: string) => `"""\n${text}\n"""`

function photoFormat(count: number): string {
  if (count === 0) return 'belum ada foto'
  return count === 1 ? 'foto tunggal' : `carousel ${count} foto`
}

function describeBrief(brief: Brief): string {
  return [
    `Topik:\n${quote(brief.topic)}`,
    `Tujuan: ${GOALS[brief.goal]}`,
    `Nada: ${TONES[brief.tone]}`,
    `Audiens: ${brief.audience || 'umum'}`,
    `Format post: ${photoFormat(brief.photoCount)}`,
  ].join('\n')
}

function taskPrompt(request: AiRequest): string {
  switch (request.task) {
    case 'captions':
      return [
        `Tugas: tulis 3 variasi caption dengan sudut pandang berbeda. ${CAPTION_SHAPE}`,
        'Format JSON: {"captions": ["…", "…", "…"]}',
        '',
        describeBrief(request.brief),
      ].join('\n')
    case 'ideas':
      return [
        'Tugas: beri 5 ide post Instagram yang berbeda-beda untuk topik di bawah. Setiap ide berupa satu kalimat yang cukup jelas untuk dijadikan topik caption.',
        'Format JSON: {"ideas": ["…", "…", "…", "…", "…"]}',
        '',
        describeBrief(request.brief),
      ].join('\n')
    case 'rewrite':
      return [
        `Tugas: ${REWRITE_INSTRUCTIONS[request.style]} Pertahankan fakta, mention, dan hashtag yang ada.`,
        'Format JSON: {"caption": "…"}',
        '',
        `Caption:\n${quote(request.caption)}`,
      ].join('\n')
    case 'hashtags':
      return [
        'Tugas: sarankan 10 hashtag relevan untuk caption di bawah, campuran hashtag populer dan spesifik. Jangan ulangi hashtag yang sudah ada di caption.',
        'Format JSON: {"hashtags": ["#…"]}',
        '',
        `Caption:\n${quote(request.caption)}`,
      ].join('\n')
  }
}

export function buildMessages(request: AiRequest): ChatMessage[] {
  return [
    { role: 'system', content: SYSTEM_PROMPT },
    { role: 'user', content: taskPrompt(request) },
  ]
```

const MAX_CAPTIONS = 3
const MAX_IDEAS = 5
const MAX_NEW_HASHTAGS = 10
const SNIPPET_LENGTH = 120

/** The model answered, but not with the JSON asked for. `snippet` is the start of its answer. */
export class AiOutputError extends Error {
  override name = 'AiOutputError'

  constructor(readonly snippet: string) {
    super(`Jawaban AI tidak bisa dibaca: ${snippet}`)
  }
}

const truncate = (text: string, max: number) => Array.from(text).slice(0, max).join('')

function snippetOf(content: string): string {
  const flat = content.replace(/\s+/g, ' ').trim()
  return lengthOf(flat) > SNIPPET_LENGTH ? `${truncate(flat, SNIPPET_LENGTH)}…` : flat
}

/** Takes the outermost `{…}`, so ```json fences or a sentence around the object don't matter. */
function readJson(content: string): Json | null {
  const start = content.indexOf('{')
  const end = content.lastIndexOf('}')
  if (start === -1 || end < start) return null
  try {
    const value: unknown = JSON.parse(content.slice(start, end + 1))
    return isObject(value) ? value : null
  } catch {
    return null
  }
}

/** Trimmed, non-empty, distinct strings, at most `max` of them. */
function cleanList(value: unknown, max: number): string[] {
  if (!Array.isArray(value)) return []
  const items = value.filter((item): item is string => typeof item === 'string').map((item) => item.trim())
  return [...new Set(items.filter(Boolean))].slice(0, max)
}

/** New tags only, normalized to `#word`, and no more than the caption has room for. */
function newHashtags(caption: string, suggested: unknown): string[] {
  const used = findHashtags(caption)
  const seen = new Set(used.map((tag) => tag.toLowerCase()))
  const room = Math.max(0, Math.min(MAX_NEW_HASHTAGS, CAPTION_MAX_HASHTAGS - used.length))
  const tags: string[] = []
  for (const text of cleanList(suggested, Number.POSITIVE_INFINITY)) {
    const tag = `#${text.replace(/[^\p{L}\p{N}_]/gu, '')}`
    if (tag === '#' || seen.has(tag.toLowerCase())) continue
    seen.add(tag.toLowerCase())
    tags.push(tag)
  }
  return tags.slice(0, room)
}

function optionsFrom(request: AiRequest, json: Json): string[] {
  switch (request.task) {
    case 'captions':
      return cleanList(json.captions, MAX_CAPTIONS)
    case 'ideas':
      // An idea becomes the topic field, so it must fit there.
      return cleanList(json.ideas, MAX_IDEAS).map((idea) => truncate(idea, TOPIC_MAX_LENGTH))
    case 'rewrite':
      return cleanList([json.caption], 1)
    case 'hashtags': {
      const tags = newHashtags(request.caption, json.hashtags)
      return tags.length > 0 ? [tags.join(' ')] : []
    }
  }
}

/** The options to show the owner. A 200 can carry a provider notice instead of JSON, so only parsed JSON counts. */
export function parseOptions(request: AiRequest, content: string): string[] {
  const json = readJson(content)
  const options = json ? optionsFrom(request, json) : []
  if (options.length === 0) throw new AiOutputError(snippetOf(content))
  return options
}

```ts
/** Requests per rolling 24 hours. 9Router's providers run on the owner's own subscriptions. */
export const DAILY_LIMIT = 100
const DAY_MS = 24 * 60 * 60 * 1000

/** The owner reached DAILY_LIMIT. */
export class AiLimitError extends Error {
  override name = 'AiLimitError'
}

interface GenerationLog {
  task: AiRequest['task']
  input: AiRequest
  output: string[] | null
  model: string
  status: 'ok' | 'failed'
  error: string | null
  duration_ms: number
}

async function countRecentRequests(): Promise<number> {
  const since = new Date(Date.now() - DAY_MS).toISOString()
  const { count, error } = await db()
    .from('ai_generations')
    .select('id', { count: 'exact', head: true })
    .gt('created_at', since)
  if (error) throw new Error(`Supabase: ${error.message}`)
  return count ?? 0
}

async function logGeneration(row: GenerationLog): Promise<void> {
  try {
    unwrap(await db().from('ai_generations').insert(row))
  } catch (error) {
    // The owner still gets the answer; only the usage log misses a row.
    console.error('[ai] gagal mencatat permintaan:', describeError(error))
  }
}

/** Checks the daily limit, asks the model, and logs the request whatever its outcome. */
export async function runAiTask(request: AiRequest): Promise<string[]> {
  const model = env('ROUTER_MODEL')
  if ((await countRecentRequests()) >= DAILY_LIMIT) {
    throw new AiLimitError(`Batas ${DAILY_LIMIT} permintaan per 24 jam tercapai`)
  }

  const startedAt = Date.now()
  const log = (result: Pick<GenerationLog, 'output' | 'status' | 'error'>) =>
    logGeneration({ task: request.task, input: request, model, duration_ms: Date.now() - startedAt, ...result })

  try {
    const options = parseOptions(request, await chatCompletion(buildMessages(request)))
    await log({ output: options, status: 'ok', error: null })
    return options
  } catch (error) {
    await log({ output: null, status: 'failed', error: describeError(error) })
    throw error
  }
}

function routerErrorMessage(status: number): string {
  if (status === 0) return 'Layanan AI tidak bisa dihubungi atau terlalu lama menjawab. Coba lagi.'
  if (status === 200) return 'Jawaban AI kosong. Coba lagi, atau ganti ROUTER_MODEL kalau terus terjadi.'
  if (status === 401 || status === 403) return 'API key 9Router ditolak. Periksa ROUTER_API_KEY di .env.local.'
  if (status === 404) return 'Model AI tidak ditemukan. Periksa ROUTER_MODEL di .env.local.'
  if (status === 429) return 'Kuota AI sedang habis. Coba lagi beberapa menit lagi.'
  if (status >= 500) return 'Layanan AI sedang bermasalah. Coba lagi nanti.'
  return `Permintaan ditolak layanan AI (HTTP ${status}). Periksa ROUTER_MODEL di .env.local.`
}

/** Owner-facing text for anything runAiTask throws. Provider details stay in the server log. */
export function aiErrorMessage(error: unknown): string {
  if (error instanceof ConfigError) return `Konfigurasi AI belum lengkap: ${error.message}.`
  if (error instanceof AiLimitError) return `Batas ${DAILY_LIMIT} permintaan AI per 24 jam sudah tercapai. Coba lagi nanti.`
  if (error instanceof AiOutputError) {
    return `Jawaban AI tidak bisa dibaca ("${error.snippet}"). Coba lagi, atau ganti ROUTER_MODEL kalau terus terjadi.`
  }
  if (error instanceof RouterApiError) return routerErrorMessage(error.status)
  return 'AI gagal dijalankan: database tidak bisa diakses. Periksa Supabase dan migrasi terbaru.'
}
```

```tsx
  hashtags: { mode: 'append', label: 'Tambahkan ke caption' },
}

const LEGEND = 'mb-2 text-xs font-semibold tracking-wide text-zinc-500 uppercase'
const LABEL = 'block space-y-1 text-sm font-medium text-zinc-900'
const FIELD =
  'block w-full rounded-lg border border-zinc-200 bg-white px-3 py-2 text-sm font-normal text-zinc-900 focus:border-zinc-400 focus:outline-none'
const PRIMARY_BUTTON =
  'rounded-lg bg-zinc-900 px-4 py-2 text-sm font-medium text-white hover:bg-zinc-800 disabled:opacity-50'
const BUTTON =
  'rounded-lg border border-zinc-200 bg-white px-3 py-1.5 text-sm font-medium text-zinc-800 hover:bg-zinc-50 disabled:opacity-50'

const entries = <K extends string>(choices: Record<K, string>) => Object.entries(choices) as [K, string][]

/** The panel sits inside the post form: Enter in a text input would submit it with its first button, Jadwalkan. */
function blockImplicitSubmit(event: KeyboardEvent<HTMLElement>) {
  if (event.key === 'Enter' && event.target instanceof HTMLInputElement) event.preventDefault()
}

interface AiAssistantProps {
  caption: string
  photoCount: number
  onCaptionChange: (caption: string) => void
}

export function AiAssistant({ caption, photoCount, onCaptionChange }: AiAssistantProps) {
  const [topic, setTopic] = useState('')
  const [goal, setGoal] = useState<Goal>('promosi')
  const [tone, setTone] = useState<Tone>('santai')
  const [audience, setAudience] = useState('')
  const [pending, setPending] = useState(false)
  const [error, setError] = useState<string | null>(null)
  const [result, setResult] = useState<{ task: AiTask; options: string[] } | null>(null)
  // Offered back while the caption is still exactly what the AI put there.
  const [undo, setUndo] = useState<{ before: string; after: string } | null>(null)

  const hasTopic = topic.trim() !== ''
  const hasCaption = caption.trim() !== ''
  const brief = { topic, goal, tone, audience, photoCount }

  async function run(request: AiRequest) {
    setPending(true)
    setError(null)
    const response: AiResult = await generateAction(request).catch(() => ({ error: 'Permintaan terputus. Coba lagi.' }))
    setPending(false)
    if ('error' in response) setError(response.error)
    else setResult({ task: request.task, options: response.options })
  }

  function apply(task: AiTask, option: string) {
    const { mode } = APPLY[task]
    if (mode === 'topic') {
      setTopic(option)
      return
    }
    const next = mode === 'append' && hasCaption ? `${caption.trimEnd()}\n\n${option}` : option
    setUndo({ before: caption, after: next })
    onCaptionChange(next)
  }

  function revert() {
    if (!undo) return
    onCaptionChange(undo.before)
    setUndo(null)
  }

  return (
    <details onKeyDown={blockImplicitSubmit} className="rounded-xl border border-zinc-200 bg-zinc-50">
      <summary className="flex cursor-pointer items-center gap-2 px-4 py-3 text-sm font-medium text-zinc-900">
        <Sparkles size={16} aria-hidden="true" />
        Asisten AI
      </summary>

      <div className="space-y-5 border-t border-zinc-200 p-4">
        <fieldset disabled={pending} className="space-y-3">
          <legend className={LEGEND}>Tulis baru</legend>
          <label className={LABEL}>
            Topik
            <textarea
              rows={2}
              maxLength={TOPIC_MAX_LENGTH}
              value={topic}
              onChange={(event) => setTopic(event.target.value)}
              placeholder="Misalnya: promo kopi susu gula aren diskon 20% akhir pekan"
              className={FIELD}
            />
          </label>
          <div className="grid gap-3 sm:grid-cols-3">
            <label className={LABEL}>
              Tujuan
              <select value={goal} onChange={(event) => setGoal(event.target.value as Goal)} className={FIELD}>
                {entries(GOALS).map(([value, label]) => (
                  <option key={value} value={value}>
                    {label}
                  </option>
                ))}
              </select>
            </label>
            <label className={LABEL}>
              Nada
              <select value={tone} onChange={(event) => setTone(event.target.value as Tone)} className={FIELD}>
                {entries(TONES).map(([value, label]) => (
                  <option key={value} value={value}>
                    {label}
                  </option>
                ))}
              </select>
            </label>
            <label className={LABEL}>
              Audiens <span className="font-normal text-zinc-500">(opsional)</span>
              <input
                value={audience}
                maxLength={AUDIENCE_MAX_LENGTH}
                onChange={(event) => setAudience(event.target.value)}
                className={FIELD}
              />
            </label>
          </div>
          <div className="flex flex-wrap gap-2">
            <button
              type="button"
              disabled={!hasTopic}
              onClick={() => run({ task: 'captions', brief })}
              className={PRIMARY_BUTTON}
            >
              Buat 3 caption
            </button>
            <button type="button" disabled={!hasTopic} onClick={() => run({ task: 'ideas', brief })} className={BUTTON}>
              Minta ide
            </button>
          </div>
        </fieldset>

        <fieldset disabled={pending || !hasCaption} className="space-y-2">
          <legend className={LEGEND}>Ubah caption</legend>
          <div className="flex flex-wrap gap-2">
            {entries(REWRITE_STYLES).map(([style, label]) => (
              <button key={style} type="button" onClick={() => run({ task: 'rewrite', style, caption })} className={BUTTON}>
                {label}
              </button>
            ))}
            <button type="button" onClick={() => run({ task: 'hashtags', caption })} className={BUTTON}>
              + Hashtag
            </button>
          </div>
          {!hasCaption && <p className="text-xs text-zinc-500">Tulis atau pilih caption dulu.</p>}
        </fieldset>

        <div className="space-y-3">
          <p aria-live="polite" className="text-sm text-zinc-600">
            {pending ? 'AI sedang menulis…' : ''}
          </p>
          {error && <Notice tone="error">{error}</Notice>}
          {undo && caption === undo.after && (
            <p className="text-sm text-zinc-600">
              Caption diganti.{' '}
              <button type="button" onClick={revert} className="font-medium text-zinc-900 underline">
                Urungkan
              </button>
            </p>
          )}
          {result && (
            <ol aria-label="Hasil AI" className="space-y-3">
              {result.options.map((option) => (
                <li key={option} className="space-y-2 rounded-lg border border-zinc-200 bg-white p-3">
                  <p className="text-sm break-words whitespace-pre-wrap text-zinc-800">{option}</p>
                  <button type="button" onClick={() => apply(result.task, option)} className={BUTTON}>
                    {APPLY[result.task].label}
                  </button>
                </li>
              ))}
            </ol>
          )}
        </div>
      </div>
    </details>
  )
}
```
